# Working in this repository

Before writing code here, read [architecture-snapshot.md](architecture-snapshot.md). Its
structure and conventions are binding:

- new code goes where it says;
- new code is written the way it says.

If a task doesn't fit them, propose the change to that file first. Once the owner approves,
make it in the same commit as the code, with the reason.

Also binding:

- [docs/WORKFLOW.md](docs/WORKFLOW.md): the workshop vs. live environments, releases, and
  the rules that keep live data safe.
- [apps/mobile/AGENTS.md](apps/mobile/AGENTS.md): for the Expo app.

Run `npm run check` before every commit.
